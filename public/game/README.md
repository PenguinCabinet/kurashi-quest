# 暮らしクエスト — ロジック確認用プレビュー

`~/kurashi-quest/src/lib/quest` を、そのままブラウザで動かして目で見るためのものです。
**本番の画面ではありません**（デザイン・UI は別担当）。チームのリポジトリには何も書き込みません。

```bash
./start.sh      # ブラウザで開く（止めるときは Control + C）
./build.sh      # ロジックを直したあと、ここに反映する
```

## ページ（本番の画面5枚と同じ並び）

| ファイル | 画面 | 見どころ |
|---|---|---|
| `index.html` | ① キャラメイク | 答えを変えると、下の件数と「要りません」が動く |
| `quests.html` | ② クエストログ | 期限別・⚠印・鍵・つぎにやること |
| `card.html?id=` | ③ やり方カード | どこで/持ち物/何て言う/時間/終わると・手順・出典 |
| `route.html` | ④ 役所攻略シート | 回る順番・持ち物1枚・注意書き |
| `sim.html?id=` | ⑤ 窓口の練習 | 持ち物が無いところで止まって出直しになる |

各ページの一番下に「**この画面が呼んでいるもの**」を出しています。
UI担当が「この画面では何を呼べばいいか」を見るための欄です。

## 触ると分かること

- 上のバーの**今日の日付**を変えると、期限と「期限切れ」が全部変わります
- 職業を社会人にすると、学生納付特例が「あなたは要りません」に回ります
- マイナンバーカードを持っていないにすると、持ち物が暗証番号 → 転出証明書に入れ替わります
- 転入届にチェックを入れると、カードの住所変更の鍵が開き、期限が実際の日付（90日後）になります
- 練習で暗証番号を「持っていない」にすると、5歩目で止まって出直しになります

進捗はブラウザに保存されます。①の「最初からやり直す」で消えます。
