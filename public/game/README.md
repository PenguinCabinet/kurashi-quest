# 確認用の画面

`src/lib/quest` のロジックが動くことを、目で見て確かめるための画面です。
**本番の画面ではありません。**素の HTML / CSS / JS で書いてあり、React には移していません。

`public/` の中なので、ビルドも設定も要らず、そのまま開けます。

```
/game              タイトル。ここから始める
/game/phone.html   パソコンから、スマホでの見え方を確認する
```

`/game` は `next.config.ts` の `redirects` で `/game/index.html` に送っています。
`public/` の中はファイル名そのままでしか配られないため、これが無いと 404 になります。

## 画面

| ファイル | 画面 | 何が見えるか |
|---|---|---|
| `index.html` | タイトル | ↑↓と Enter で選ぶ |
| `chara.html` | ① あなたのこと | 6問。答えるたびに、要る手続きと持ち物が動く |
| `quests.html` | ② クエストログ | 章・期限・前提・得るもの・放っておくとどうなるか |
| `card.html?id=` | ③ やり方カード | どこで / 何て言う / 持ち物 / 手順 / 出典 |
| `route.html` | ④ 回る順番 | 同じ場所をまとめて、前提のある順に並べる |
| `sim.html?id=` | ⑤ 窓口の練習 | 1件だけの会話。持ち物が無いと出直し |
| `counter.html` | ⑥ 窓口 | 準備 → 歩いて移動 → 受付。複数件を続けて回る |

各ページの一番下に「**この画面が呼んでいるもの**」を畳んで置いてあります。
どの画面が、ロジックのどの関数を呼んでいるかの一覧です。

## 触ると分かること

- 引越し日を過去にすると、期限切れが出ます（`?today=2026-08-20` でも動かせます）
- 「働いています」にすると、国民年金の学生納付特例が「あなたには要らないもの」に回ります
- マイナンバーカードを持っていないにすると、持ち物が暗証番号 → 転出証明書に入れ替わります
- 転入届を達成にすると、カードの住所変更の前提が外れ、期限が実際の日付（90日後）になります
- かばんに入れずに市役所へ行くと、窓口で断られて出直しになります

## 直すときの注意

`quest/*.js` は **`src/lib/quest/*.ts` から生成したコピー**です。
ここを手で直すと、ロジックが二重管理になります。**直すのは `src/lib/quest` 側だけ**にしてください。

やっていることは、TypeScript を JS に変換して `quest/` に置き、
`import "./x.ts"` を `"./x.js"` に書き換えるところまでです。
`quest/procedures.js` は `src/data/procedures.json` を `export default` で包んだものです。

## 状態の持ち方

答えと進み具合は、ブラウザの localStorage に入ります。サーバーには何も送りません。
タイトルの「はじめから」で、答えも達成もまとめて消えます。
