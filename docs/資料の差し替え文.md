# スライドに載せる内容

7枚。そのまま貼れる形にしてあります。

---

## 1枚目 タイトル

```
暮らしクエスト

引越しの手続きを、窓口で出直さないためのゲーム。

チーム名：チーム孤独な若者と共に
```

右の4つ。

```
1. キャラメイク     6つの質問に答える
2. 依頼が出る      自分に要る手続きだけ、期限順に並ぶ
3. かばんに詰める    持っていくものを選ぶ
4. 窓口へ行く      足りないと帰される。出直した回数が残る
```

```
若者の認識

```

## 3枚目 サービス概要

```
サービス概要

キャラメイクから「自分用の攻略ルート」を作り、窓口まで連れていく
```

4つの丸。

```
1  キャラメイク      6問。学生か、いつ引越したか、車はあるか
2  依頼が出る       自分に要る手続きだけ。期限順・前提順に並ぶ
3  かばんに詰める     家で入れたものしか、窓口で出せない
4  窓口で出直す      用件を選び、持ち物を出す。足りないと帰される
```

下の帯。

```
ToDoリストとの差    ToDoリストは、失敗させてくれない。
```

## 4枚目 今回こだわって実装した内容

```
今回こだわって実装した内容

ロジック側：抽出・並べ替え・集約で攻略ルートを作る
```

左の箱（入力例）。

```
入力例

学生ですか？          → 学生です
いつ引越しましたか？     → 2026-08-14
マイナンバーカードは？    → 持っている
ひとり暮らしですか？     → はい
車やバイクは？         → 原付
20歳以上ですか？       → はい

キャラメイクで回答
```

真ん中の箱。

```
攻略ルート生成ロジック

1. 抽出      条件に合う手続きだけ選ぶ
2. 並べ替え    期限順に並べ、トポロジカルソートで前提のあるものを後ろへ
3. 集約      同じ窓口で回れるものをまとめる
```

右の箱（出力例）。

```
出力例

1. 転出届を出す（前に住んでいた市）
2. 電気・ガス・水道を止めて、新居で開ける（家でできる）
3. 郵便の転送届を出す（郵便局）
4. 転入届を出す
5. マイナンバーカードの住所を書き換える
6. 国民年金の学生納付特例を出す
7. 原付のナンバープレートを取り直す

出かける回数 3回 ／ 合計105分
持ち物 のべ17件 → 8種にまとめた
```

下の黒い帯。

```
技術メモ：Next.js 16 / TypeScript / ロジック層はReactに依存しない
　　　　　保存はブラウザ、端末をまたぐときは合言葉（Vercel Blob・非公開）
　　　　　テスト185件
```
