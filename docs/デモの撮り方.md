# デモの撮り方（45秒）

発表で流す画面録画の台本です。**わざと1回失敗させてください。**成功だけ映すと、ただの手続き一覧に見えます。

開くのはこちらです。パソコンでもスマホでも動きます。

```
https://kurashi-quest.vercel.app
```

撮る前に、**タイトルの「はじめから」を押してまっさら**にしてください。前に触った達成が残っていると、いきなり「ぜんぶ終わりました」が映ります。

---

## 台本

| 時間 | 映すもの | 操作 |
|---|---|---|
| 0:00–0:06 | タイトル | そのまま6秒見せる。柴犬が「引越しの手続き、ぼくが案内します」と言っている |
| 0:06–0:18 | キャラメイク | 6問を続けて答える。**答えるたびに下の「持ち物が増えました」が出るところ**を見せたい |
| 0:18–0:24 | クエストログ | 依頼札を1つ開く。「得るもの」「放っておくと」が見えるところで止める |
| 0:24–0:30 | 出かける準備 | **かばんを1つだけ入れて**「市役所へ行く」を押す |
| 0:30–0:34 | 歩く場面 | 何も操作しない。3秒歩く |
| 0:34–0:42 | 窓口 | 用件を選ぶ → 持ち物を出す → **足りずに断られる** |
| 0:42–0:45 | 完了 | 家に戻ってかばんを全部入れ、もう一度行って完了の判が押されるところ |

最後の3秒が短ければ、**0:34–0:45 を「断られる」だけにして、完了は静止画**でも構いません。断られる場面の方が大事です。

---

## 見せどころ

```
0:06–0:18  答えると件数が変わる     → 検索ではなく「答える」形だと伝わる
0:34–0:42  窓口で断られる          → このアプリが何を防ぐものか、一発で伝わる
```

この2つが入っていれば、他は削って構いません。

---

## 撮るときの設定

```
音        出したまま（左下のボタンが「音を止める」なら、いま音は出ています）
ブラウザ    全画面にせず、ウィンドウのままでよい
文字の大きさ  そのまま。スライドに載せると小さくなるので、必要なら Command + でひとつ拡大
```

**スマホで撮るなら**、こちらで見え方を確認できます。

```
https://kurashi-quest.vercel.app/phone.html
```
